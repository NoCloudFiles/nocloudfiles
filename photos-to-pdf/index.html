What this tool can and cannot do

What it does

  • Puts each photo on its own A4 page, whole and in proportion.
  • Checks the actual PDF size against the limit you choose.
  • Lets you reorder, rotate and crop the edges you choose.
  • Stops with a clear message instead of silently dropping pages.

What it does not do

  • Compress or convert existing PDFs, Word files or signed forms.
  • Create searchable text. The PDF is image-based.
  • Guarantee that a website accepts the file.
  • Keep Live Photo video. HEIC uses the still image only.

Questions

Can I compress an existing PDF here?

No. This tool turns photos into a PDF. Existing PDFs, Word documents, fillable forms and digital signatures have structures this tool does not preserve. Use the original document when searchable text or signed forms are required.

What if my photos or the final PDF are too large?

Each photo can be up to 20 MB, with 80 MB in total. Resize very high-resolution photos first. If the PDF is still too large at the lowest quality setting, processing stops. Remove unnecessary pages, crop unused edges, or split the submission if permitted. Pages are never silently dropped.
