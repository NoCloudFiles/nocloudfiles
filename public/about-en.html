Less hassle preparing documents

NoCloudFiles is a free set of seven browser-local tools for photos, PDF scans, tables/CSV files, schedules and contacts backups. Every tool runs on your device in this browser with no account, no cloud library and no file upload endpoint.

The seven tools and their limits

1. Photos to PDF (/photos-to-pdf/)

Combine up to 20 JPG, PNG, WebP or HEIC photos into one A4 PDF that fits a chosen byte limit. Supports reordering, rotation and manual edge cropping. Limits: 20 MB per photo, 80 MB total, 36 million pixels per photo (1 MB = 1,000,000 bytes). Actual output PDF bytes are checked; if the lowest quality step still exceeds the limit, processing stops instead of dropping pages.

Does not: edit or compress existing PDFs, Word documents or signed forms; preserve Live Photo video (HEIC uses the still primary image only); provide OCR or searchable text; or guarantee that any upload portal will accept your submission. Check readability, orientation and page order before submitting.

2. Photo privacy check (/photo-privacy/)

Inspect EXIF, XMP and GPS metadata in an original JPEG or HEIC/HEIF still photo up to 32 MB and 50 megapixels, then build a shareable still JPEG copy. By default all metadata, thumbnails, maker notes and unrecognized segments are removed; only the fields you explicitly tick are written back into XMP and verified by re-opening the copy.

Does not: hide addresses, faces or other details visible in the image pixels; process the paired video of a motion photo; edit every specialized metadata field (some are view-only); or modify your original file. HDR photos export at standard brightness, and images exceeding browser canvas pixel ceilings are scaled proportionally when re-encoding is needed.

3. Mix front & back scans (/interleave-pdf/)

Interleave two PDFs from a single-sided scanner (front odd pages and back even pages) into reading order. Reverses the back stack by default (or keeps forward order), optionally rotates back pages by 180° while preserving existing page rotation, and copies pages losslessly without re-compressing scans or stripping text layers. Limits: 50 MB per PDF, 80 MB and 500 pages combined. If the page counts differ, you are warned and the extra pages are added at the end.

Does not: unlock password-protected or encrypted PDFs; run OCR, deskew crooked scans, crop margins or edit page content; automatically detect upside-down pages or remove blank back sides; repair damaged PDFs; or split one already-mixed PDF into front and back halves.

4. CSV check (/csv-check/)

Check quoting, column counts and strict character encoding (UTF-8, UTF-16 BOM or explicit Windows-1252, GB18030, Big5), preview cells and export a comma-separated, CRLF, quoted UTF-8 CSV with BOM. Limits: 2 MB, 20,000 records (including the first row) and 200 columns. Broken quoting, inconsistent rows or ambiguous delimiters block export; formula-like cells require an explicit choice to escape with a leading apostrophe or preserve as-is.

Does not: repair broken quotes or inconsistent column counts; recover leading zeros or precision already lost by spreadsheet software; guess ambiguous dates; or validate Shopify, Stripe, accounting or other platform business rules. Editing the text box normalizes line endings; unedited uploaded files preserve embedded line endings.

5. Compare two CSVs (/csv-diff/)

Compare an original and updated CSV or TSV table by 1 or 2 unique key columns before re-importing. Flags cells wiped from non-empty to blank, columns dropped or added, row additions/removals/edits, and optionally sums one numeric column with exact decimal arithmetic (including full-column sign-flip detection). Exports a UTF-8 BOM diff CSV after an explicit formula choice when needed. Limits: 2 MB, 20,000 records and 200 columns per table.

Does not: guess row matches when keys are blank or duplicated (comparison stops with exact record numbers); coerce currency symbols, thousand separators, scientific notation or text to 0 (unparseable cells are counted separately); repair broken CSV syntax; or validate ERP, Shopify, payroll or accounting business rules.

6. Schedule to calendar (/schedule-to-calendar/)

Paste a shift list, exam timetable or match schedule from a spreadsheet or open a CSV/TSV file (up to 2 MB). Map columns, resolve ambiguous numeric dates explicitly (MM/DD vs DD/MM), preview overnight shifts and all-day events, and export a floating local-time ICS file and a Google Calendar CSV.

Does not: guess ambiguous dates or attach an automatic IANA timezone database. Import into a separate test calendar first and verify event counts and local times. Mobile handling of multi-event ICS files varies by device and app; Google Calendar officially supports desktop web import.

7. Select contacts (/vcf-select/)

Read a vCard 2.1, 3.0 or 4.0 backup (up to 30 MB) in a local browser worker, including vCard 2.1 Quoted-Printable soft line breaks and declared charsets. Search people, pick only the people and fields you want to share, preview the exact output text, and download a reconstructed UTF-8 vCard 3.0 file.

Does not: import contacts into your system address book, skip a backup it cannot fully read (it shows an error instead), or keep embedded photos and private extension fields (selected names are always included; photos and private extension fields are omitted).

Privacy and optional analytics

Your photos, PDFs, CSV text, schedules, contacts and filenames stay in your browser. Refreshing or closing a tool discards the current work. Cloudflare hosts the static files and processes normal network connection information, so visiting any website, this one included, is not anonymous by default.

Optional Google Analytics (GA4) loads only if you choose “Allow analytics”. Consent is stored in localStorage as the single analytics preference. When allowed, it receives bounded usage events, interface language, tool ID, selected target tool, input source (sample, file or mixed), fixed error categories and optional fixed feedback categories, plus normal connection information processed by Google. Files, filenames, pasted text, cell values, contacts, dates and free-text notes are never sent by our analytics code. URL query parameters and fragments are stripped except for an allowlisted set of known referral source identifiers (utm_source, such as chatgpt.com, and optional allowlisted utm_medium values). Advertising signals and enhanced measurement are disabled. You can withdraw consent at any time via “Analytics settings” in the footer; declining or blocking analytics never prevents any tool from working.

How we evaluate usefulness

Built-in samples and automated tests verify program behavior, not real-world usefulness. We separate sample runs from user-supplied files or text, and generating output and clicking download are separate events. Neither proves a file was saved or accepted by another website. Notes typed in the optional feedback dialog are copied locally only when you ask and are never transmitted.
