No VCF file yet? How to export your contacts
  1. iPhone: open Contacts → Lists (top left) → touch and hold the list to export → Export, choose fields, then save to Files.
  2. Android (Google Contacts): tap Fix & manage → Export to file → choose the account → export as .vcf. Older versions: Menu → Settings → Export.
  3. Computer: select all contacts on iCloud.com or Google Contacts on the web, then export a vCard.
